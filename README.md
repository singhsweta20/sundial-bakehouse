# Sundial Bakehouse 🥐

Official website repository for *Sundial Bakehouse* — an artisanal bakery and café on Dumra Road, Rajopatti, Sitamarhi.

## 🌟 Key Features
- *Local SEO & Schema Integration:* Included JSON-LD schema for local business ranking on Google.
- *Responsive Layout:* Optimized for desktop and mobile screens with custom CSS grid and flexbox.
- *Dynamic Menu Tabs:* Intersecting tab system to browse morning and afternoon offerings.
- *Direct Ordering:* WhatsApp integration and direct contact links for easy customer inquiries.
- *Interactive UI:* Smooth scrolling, animated sundial element, and scroll-triggered animations.

## 🛠️ Built With
- *HTML5:* Semantic architecture, metadata, and JSON-LD structured data.
- *CSS3:* Flexbox, CSS Grid, keyframes animation, and dynamic design variables.
- *JavaScript (Vanilla):* DOM updates for mobile navigation, tab switches, and reveal animations.
